# Weather-Analytics-Forecast-Decision-Support-System
A desktop application built using Electron that integrates with OpenWeatherMap REST API to analyze weather data, convert units, and suggest suitable activities based on current forecasts.

## Features
- **Live Weather Analytics:** Fetches real-time weather data via OpenWeatherMap REST API.
- **Unit Conversion:** Displays temperature in Celsius, Fahrenheit, and Kelvin.
- **Activity Decision Support:** Suggests indoor/outdoor activities based on weather conditions.
- **Itinerary Manager:** Complete CRUD features (Create, Read, Update, Delete) with local JSON storage.

## Tech Stack
- **Framework:** Electron.js
- **API:** OpenWeatherMap REST API
- **Data Storage:** Local JSON
- **Languages:** JavaScript, HTML, CSS
